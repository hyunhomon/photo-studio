# 베타 운영 및 실제 계정 검증

## 검증 상태와 외부 준비

로컬/production Mock 전체 흐름은 합성 사진·합성 사용자로 검증한다. 2026-11-11 런타임 수정 재배포 후 사용자가 실제 OpenRouter OAuth 연결과 스튜디오 진입 성공을 확인했다. nullable OAuth user_id의 다른 계정 유형별 반환, funded 계정의 유료 분석/이미지/평가 성공과 의류 보존 품질은 추가 검증이 필요하다. 실제 키나 OAuth code를 채팅/로그에 붙이지 않는다.

운영자 공용 OpenRouter API key는 필요 없다. 사용자가 자신의 OpenRouter 계정과 크레딧을 준비하고 UI의 OAuth로 연결한다. 초대 코드는 필요 없다. 홈페이지의 OpenRouter 시작 버튼으로 바로 연결한다(ADR-016). Cloudflare 계정 로그인과 AES secret/D1/R2/Workflow는 배포 명령이 준비한다.

## 실제 유료 smoke — 사람의 명시적 실행만

- [x] 홈페이지에서 OpenRouter로 시작해 실제 계정으로 로그인한다. callback이 initiating browser 및 stable user_id에 연결되는지 확인한다. 반환되지 않으면 안전하게 실패하며 임의 계정 합치기/공용 키 우회는 하지 않는다. 사용자 스튜디오 진입 확인; 실제 user/connection/session 각 1개를 식별자 없는 집계로 확인했다.
- [ ] 권리를 보유한 작은 의류 사진 1장(로고/패턴 포함 권장)을 비공개 업로드한다. 이 동작만으로 OpenRouter AI 호출이 생기지 않는지 확인한다.
- [ ] 모델 및 비용 안내를 확인하고 분석/기획 2단계 호출을 직접 승인한다. 결과의 불확실성을 확인하고 상품 보존 포인트와 콘셉트를 수정·승인한다.
- [ ] 별도 비용 안내 후 medium 1장 + 품질 평가를 직접 승인한다. OpenRouter 사용 내역과 앱의 실제 비용/미확인 표기를 대조한다. 비용이 누락됐다고 0달러로 처리하지 않는다.
- [ ] 원본/결과의 로고·색상·패턴·단추·길이·핏을 확대 비교한다. AI 점수에 관계없이 사람이 채택/폐기하고 구체적 사유를 기록한다.
- [ ] 필요할 때만 추가 비용을 알고 재생성한다. 미확인 응답은 제공자 사용 내역을 먼저 확인하며 자동 재전송하지 않는다.
- [ ] PNG와 기록 JSON을 다운로드하고 프로젝트 삭제 후 사진 접근이 막히는지 확인한다. 연결 해제/키 폐기는 제공자 화면에서도 확인한다.

위 항목은 코드·Mock 테스트 통과만으로 체크하지 않는다. 실제 고객 사진의 최대 크기/다중 업로드 부하, provider별 의류 보존 성능, 암호화 키 회전·D1 백업 복구 리허설도 별도 운영 검증으로 남긴다.

## 5~10개 베타 고객 인터뷰

1. 최근 시즌 촬영에서 모델·스튜디오·인력·후처리에 실제 지출한 금액과 통화, 상품/컷 수, 소요 시간을 각각 적는다. 확인되지 않은 업계 평균을 대입하지 않는다.
2. 사진 1장으로 첫 채택 컷까지 몇 분이 걸렸는가? 실행/기획 수정/수동 검수 시간을 구분한다.
3. 전체 생성 컷 중 판매 페이지에 실제 쓸 컷은 몇 장인가? 채택하지 않은 이유를 색상·로고·패턴·핏·누락·자연스러움·구도로 나눈다.
4. 스튜디오 모델컷과 가상 로케이션컷 중 어느 용도가 유용했는가? 어떤 상품군에서 원본 보존이 특히 어려웠는가?
5. AI 평가가 놓친 오류나 과도하게 경고한 부분은 무엇인가? 사진만으로 판단할 수 없는 소재/치수가 올바르게 불확실로 표시됐는가?
6. OpenRouter의 실제 청구액과 앱의 확인된 비용 부분합·미확인 횟수를 비교한다. 채택 컷당 총 비용 계산에는 실제 확인된 비용만 사용한다.
7. 기존 촬영 중 실제로 대체할 수 있는 범위는 어디까지인가? 기존 전체 촬영 예산을 모두 절감했다고 가정하지 않는다.
8. OAuth/업로드/비용 승인/삭제 과정에서 혼동·불안·복구 어려움이 있었는가?
9. 반복해 쓰고 싶은 모델 스타일·브랜드 무드·장소 프리셋은 무엇인가?
10. 공개 출시 전에 반드시 개선돼야 할 오류 3가지를 순서대로 고른다.

고객별 기록 양식: 인터뷰 일자 / 동의 받은 익명 코드 / 상품군 / 기존 실제 촬영비·통화 / 기존 실제 컷 수·시간 / 생성·채택·폐기 수 / 사유별 횟수 / 실제 AI 비용·미확인 건수 / 검수·편집 시간 / 대체 가능한 컷 수 / 실제 대체 비용(확인된 경우만). 정보는 고객 동의 범위에서 비공개 보관한다.

## 관리 통계

고객용 `/studio/usage`는 본인 기록만 표시한다. 관리자용 공개 API나 다른 사용자 조회 화면은 만들지 않는다. 운영 통계는 Cloudflare D1 관리 권한으로 **집계값만** 조회한다. 키·사진·프롬프트·계정 식별자를 출력하지 않는다. `is_test=1` 합성 계정은 실제 품질·비용 지표에서 제외한다.

```sql
SELECT a.stage, a.model, a.status, count(*) AS calls,
       count(a.actual_cost_usd) AS cost_known_calls,
       sum(a.actual_cost_usd) AS known_cost_subtotal_usd,
       avg(a.duration_ms) AS average_latency_ms
FROM generation_attempts a JOIN users u ON u.id=a.user_id
WHERE u.is_test=0 GROUP BY a.stage,a.model,a.status;
```

채택률은 최신 feedback 기준으로 계산한다. 사람 검수 컷 분모와 AI 평가 완료 컷 분모를 구분하고, 삭제된 자료는 집계에서 빠진다. 재생성 사유/이전 결과 연결은 작업 snapshot에 저장된다. 자세한 고객 이력은 고객이 직접 내보내거나 동의한 범위에서만 다룬다. 목표 채택률은 PRD 가설이며 달성한 실적으로 표시하지 않는다.
