# PRD — Photo Studio MVP

**상태:** Accepted · ADR-019 반영 2026-11-12 · **최초 작성일:** 2026-11-10 · **플랫폼:** 웹

## 1. 문제와 가치 제안

쇼핑몰의 시즌 촬영에는 모델 인건비, 스튜디오 대여, 촬영 인력, 후처리 비용이 발생한다. 규모에 따라 1회 예산이 1,000만 원 수준이 될 수 있으나 이는 **검증되지 않은 모든 쇼핑몰 평균이 아니라 고객별 비교 기준**이다.

Photo Studio는 **의류 이미지를 업로드하면 촬영 기획부터 모델·로케이션 화보 생성까지 자동화**해 반복 촬영 부담을 줄인다. 일반 GPT 프롬프팅보다 나은 사용 경험과 상품 보존 검수·브랜드 재사용성을 판다.

## 2. 타깃 및 검증

- 1차: 시즌별 신상품을 출시하는 소규모~중형 의류 쇼핑몰 운영자
- 2차: 상품 촬영·상세페이지 제작 프리랜서 / 대행사
- 클로즈드 베타 5~10개 운영 조직 인터뷰
- 핵심 질문: 실제 판매 페이지에 올릴 컷을 제작할 수 있는가? 기존 촬영의 어느 구간을 대체하는가?

## 3. 핵심 사용자 플로우

1. 초대 코드 없이 OpenRouter OAuth로 바로 로그인/계정 연결 (사용자 지시 변경, ADR-016).
2. 프로젝트를 만들고 의류 정면 사진 1장 업로드(추가 후면/디테일은 선택, 최대 3장 제안). **파일 업로드 자체는 AI 비용이 들지 않는다.**
3. 사용자가 OpenRouter 비용 안내 후 `분석 시작`을 누르면 상품 분석: 카테고리·색·소재 추정·실루엣·계절감·텍스트/로고 등 보존 포인트 제시.
4. 촬영 기획: 시즌·브랜드 무드·모델 스타일·촬영 구도·로케이션 추천. 불확실한 분석 결과는 수정 가능.
5. 사용자가 촬영 콘셉트 및 **예상 API 소모/고객 부담**을 확인하고 '생성' 실행.
6. OpenRouter의 사용자별 키로 GPT Image 2 이미지 생성(기본 1장, 추가 생성은 명시적 클릭).
7. 사용자가 원본/이전 컷과 확대 비교한다. 상품 보존을 전제로 빛·초점/인물/소재를 확인하며 AI 점수나 채택/폐기 피드백을 요구하지 않는다.
8. 필요한 경우 개선 항목·자유 지시를 입력하고 별도 비용에 동의해 1장 생성한다. 이전 컷은 연속성 참조로 사용하고 원본 의류가 우선한다. 결과 다운로드 및 기록 재조회 가능.

## 4. MVP 필수 범위

### P0
- OAuth PKCE S256 + 내부 세션 + 서버 암호화된 API Key
- 초대 게이트 없는 OpenRouter 직접 연결
- 프로젝트 생성/목록/삭제
- 제품 이미지 업로드 및 사설 R2 저장
- 상품 분석 JSON + 사용자가 간단 수정하는 UI
- 자동 촬영 콘셉트 추천 및 수정
- 하나의 촬영 파이프라인; 장소·시간·조명·구도·배경 분리·성인 외모 묘사·소재 지시 수정 및 재사용
- 진행 상태/실패 이유/다시 시도 UX
- 원본/결과 및 이전 컷 비교·확대, 다운로드
- 빛·초점/인물/소재 중심의 수동 비교 안내와 사용자 동의 기반 지시형 컷 개선
- API 비용(제공 시 실제, 불가 시 미확인), 생성 횟수, 지연, 재생성 항목·지시·연결, 촬영 프로토콜/프롬프트 버전 기록
- 브랜드 프리셋(모델 스타일/무드/로케이션) 저장·재사용

### P1 (품질 여력이 있을 때)
- 비교 화면의 줌/슬라이더
- 생성 프롬프트 버전 관리 화면
- 촬영 이력 필터링과 CSV 내보내기

### 명시적 제외
- 서비스 자체 결제, 구독, 크레딧, 무제한 사용권
- 모델 훈련, 쇼핑몰 직접 업로드, SNS 게시 자동화
- 여러 상품 대량 배치 처리, 팀 협업, 브랜딩 로고 생성
- 무제한 자동 재생성, 작업자 없는 자동 품질 확정, AI 점수·채택/폐기 피드백, 웹 얼굴 수집/얼굴 신원 고정

## 5. 제안 기본값 (개발 시 합리적으로 수정 가능)

- 이미지 입력: JPEG/PNG/WebP, 파일당 최대 10MB, 상품당 최대 3장
- 결과: 기본 3:4, high/medium 품질 선택 가능, 기본 1장
- 세션: 서버 관리 · Secure/HttpOnly cookie · CSRF/세션 갱신 전략 필수
- 프로젝트 및 R2 이미지: 사용자가 삭제할 때까지 저장(데이터 보존/삭제 정책 고지)
- 초대 코드 없이 직접 OpenRouter OAuth(ADR-016)
- 기본 UX: 업로드 → **과금 안내 후 분석 시작 승인** → 분석/기획 → **별도 과금 안내 후 이미지 생성 승인**. 파일 선택만으로 AI API 호출 금지.

## 6. 성공 지표 (가설/측정 목표)

| 지표 | 정의 | 목표/해석 |
|---|---|---|
| 현장 사용 가능성 | 별도 고객 인터뷰에서 실제 판매 페이지에 쓸 수 있는지 확인 | 앱의 AI 점수/채택 버튼으로 대체하지 않음 |
| 생성당 AI 비용 | 확인된 실제 비용 부분합 / 생성 수, 미확인 호출 수 병기 | 실제 값 측정; 추측 비용과 분리 |
| 상품 충실도·촬영 일관성 | 사람이 원본/이전 컷의 상품 보존, 빛·초점/인물/소재를 비교 | 한 항목씩 수정; 새 모델 점수를 정답으로 삼지 않음 |
| 작업 성공률 | 작업 성공 / 작업 시작 | 외부 API 오류 분리 |
| 전환 비용 절감률 | (기존 촬영 실제 비용 - AI 제작 후 전체 비용) / 기존 비용 | 고객별 실제 금액으로만 계산 |
| 최초 사용 가능 컷까지 시간 | 인터뷰에서 업로드부터 사용 가능하다고 판단한 컷까지 | 실제 촬영시간과 비교, 앱 자동 채택률은 종료 |

숫자는 벤치마크가 아닌 내부 가설이다. 고객이 촬영 1,000만 원을 절감한다고 단정하지 말 것.

## 7. 후속 비즈니스 모델 (MVP 구현 금지)

정식 출시 시 **기본 구독 크레딧 + 추가 크레딧 구매**. 모든 모델 호출 비용을 서비스가 부담하는 구조로 전환하므로, MVP 수집 데이터로 요금/소모량/공헌이익 설계. 기존 후보 가격 Starter 39,000원 / Pro 99,000원 / Studio 249,000원은 **검증되지 않은 가격 가설**일 뿐이다.
