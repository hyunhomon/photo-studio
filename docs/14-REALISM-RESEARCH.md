# 촬영 현실감 — 리서치, 구현, 검증 루프

2026-11-12 · ADR-019/020 · 현재 `studio-v4-retail` / `photo-v2-retail` (v1 기록 보존)

## 제품의 판단 기준

원본 의류의 색·로고·핏을 보존하면서 **빛과 초점의 일관성 / 인물의 자연스러움 / 의류와 주변 소재 표현**을 개선한다. 자동 점수나 기술 용어의 수를 품질 성과로 간주하지 않는다. 스튜디오와 가상 로케이션은 별도 기술 파이프라인이 없으므로 모드를 제거했다. 장소·시간·조명·구도는 실제 촬영 지시로 유지한다.

## 관찰과 추론을 구분하기

- 읽기 전용 집계에서 기존 실제 생성 5건 모두 realism=0.9였다. backend가 고정 90점을 넣은 것은 아니지만 분별력·인간 판단과의 보정이 검증되지 않았다. AI 평가와 점수·채택/폐기 피드백을 종료했으며 기존 비용/데이터는 보존한다.
- 원본과 기존 출력 2건을 비공개로 비교했다. 배경은 이미 상당히 흐렸다. 피부 보정감, 균일한 원단, 작은 상품 디테일의 변형이 더 뚜렷했다. 이는 작은 표본의 관찰이며 전체 모델 성능이나 실패 원인의 통계적 증명은 아니다. 실제 사진·식별자·사용자 지시 원문은 저장소/로그에 남기지 않는다.
- 낮은 해상도 원본에서 섬유·작은 표식의 정확한 모양을 추론하는 데는 정보 한계가 있다. 충분한 크기의 정면+로고/소재 근접 사진을 권장한다. 1024px 권장과 640px 미만 안내는 UX 휴리스틱이지 모델 성능 임계값이나 품질 보증이 아니다. 저해상도 업로드도 계속 허용한다.
- 기존 재생성 사유는 기록됐지만 이미지 프롬프트에 전달되지 않았다. 새 버전은 항목별 수정 지시와 사용자의 구체적 요청을 실제 입력으로 전달한다.

## 왜 ‘AI 티’가 생기는가

### 빛·초점: 하자를 더하기보다 한 카메라와 한 공간의 일관성

실제 사진의 심도와 배경 흐림은 조리개뿐 아니라 초점거리, 피사체 및 배경 거리의 영향을 받는다. 모든 곳이 선명한 상업 사진도 정상이다. 따라서 무조건 얕은 심도나 랜덤 블러가 더 사실적이라는 결론은 성립하지 않는다. [Nikon의 보케 설명](https://www.nikonusa.com/learn-and-explore/c/tips-and-techniques/bokeh-for-beginners)을 근거로, 상품·눈을 읽을 수 있는 초점 범위와 거리에 따른 점진적 흐림을 지시한다.

광원 방향/크기, 얼굴·옷·배경의 노출, 접촉 그림자, 주변 반사광이 서로 어긋나면 합성처럼 느껴질 수 있다는 작업 가설을 세웠다. 모든 구획에 독립적인 스튜디오광을 두거나 HDR로 그림자를 지우지 않게 한다. 모공/옷감은 해상도와 초점이 허용하는 범위에서만 남기고, 노이즈·비네팅·색수차·JPEG 열화·렌즈 오염을 일괄 덧씌우지 않는다. 상품 정보가 사라지는 ‘하자’는 허용하지 않는다.

### 인물: 대칭성 하나보다 부위별 현실감의 불일치

Chattopadhyay/MacDorman의 실험은 눈·피부 등 특징의 현실감이 어긋날 때 사람/동물 표현의 친숙함과 불쾌감이 영향을 받는다는 근거를 제공한다. 이 연구가 현 이미지 모델을 직접 평가한 것은 아니다. ‘과도한 대칭만 없애면 해결’로 단순화하거나 일부러 얼굴을 일그러뜨리는 대신 눈/입/피부/머리카락을 같은 현실감 수준으로, 자연스러운 시선·표정·어깨와 손의 긴장·무게 중심을 함께 지시한다. [Journal of Vision 원 연구](https://pubmed.ncbi.nlm.nih.gov/27611063/), [Cognition 원 연구의 저자기관 저장소](https://scholarworks.indianapolis.iu.edu/items/d82b9253-19d7-49a4-87f6-88ea71f80c08).

생성 얼굴이 항상 구별되는 것도 아니다. 특정 합성 얼굴을 대상으로 한 연구 결과를 최신 모델·전신 패션 이미지 전체에 그대로 일반화할 수 없다. [Nightingale/Farid, PNAS 2022](https://doi.org/10.1073/pnas.2120481119).

이번 구현은 **가상의 성인 외모 묘사**와 **같은 상품의 이전 생성 컷 참조**다. 묘사는 신원 고정 기능이 아니며 이전 얼굴/자세의 보존도 보장하지 않는다. 외부 웹 얼굴 수집·실제 얼굴 전용 업로드·권리 확인/동의/삭제 체계를 구현한 것으로 표시하지 않는다. 이 별도 기능을 도입하려면 출처와 사용 권한이 명확한 얼굴 참조, 입력 역할 분리, 초상 삭제 정책부터 설계해야 한다.

### 소재: ‘고해상도 텍스처’라는 한 단어로는 부족

Cornell의 직물 연구는 섬유 미세구조와 빛의 산란/차폐, 불규칙성이 재질 외관을 구성함을 다룬다. [Cornell CT cloth 연구](https://www.cs.cornell.edu/projects/ctcloth/). 이를 프롬프트 설계에 적용해 원본에서 관찰한 짜임·기모·봉제 간격·두께, 중력과 접촉에 따른 주름, 피부/옷/돌/나무/금속의 서로 다른 거칠기·반사 반응을 구분한다. 근거 없는 윤기·헤짐·새 봉제선은 만들지 않는다. 이 앱이 섬유 단위 물리 렌더러를 구현한 것은 아니다.

### 점수 제거의 근거와 한계

일부 멀티모달 모델은 미세한 색 차이나 이미지간 품질 비교에 약할 수 있다는 실험 결과가 있다. [Wu 외, ECCV 2024](https://www.ecva.net/papers/eccv_2024/papers_ECCV/html/9400_ECCV_2024_paper.php). 당시 시험 모델의 결과이므로 현 평가 모델이 반드시 같은 약점을 가진다고 단정하지 않는다. 이번 결정은 사용자 요청과 실제 5건 점수의 낮은 구분력에 근거한다. 임의로 점수 분산을 키우거나 다른 AI 점수를 정답처럼 노출하지 않는다.

## 첫 루프(v1)에서 구현한 제어와 안전 경계

- `packages/ai/src/photography.ts`: 촬영 프로토콜/불변 상품 조건/참조 역할/수정 지시를 명시적으로 컴파일한다. 기획의 외모 묘사·배경 분리·소재 지시는 편집/프리셋 재사용이 가능하다.
- 은은한/자연스러운/분리감 있는 배경은 각각 50mm f/8, 70mm f/5.6, 85mm f/5.6의 근사 프로필에 거리 조건을 연결한다. full-frame CoC 0.03mm의 thin-lens 근사로 초점 범위와 배경 분리의 순서를 검사한다. 생성 이미지의 EXIF/실제 광학/물리 정확도를 측정한 값은 아니다. 별도 깊이 추정이나 후처리 블러도 없다.
- 원본 1–3장은 상품 증거, 추가 이전 컷 1장은 가상 인물/구도 연속성 참조다. 원본 의류가 항상 우선이다. `input_references`와 실제 참조 수의 지원 여부를 모델 catalog에서 검사한다. 공식 계약: [OpenRouter Images API](https://openrouter.ai/blog/tutorials/image-generation/), [OpenAPI](https://openrouter.ai/openapi.json).
- `lighting_focus` / `human_naturalness` / `material_rendering`와 기존 상품 오류 항목을 선택하고 자유 지시를 전달한다. 별도 개선 요청은 이미지 1장 과금 동의를 받는다. 결과와 이전 컷·원본을 모두 비교할 수 있다.
- 승인된 snapshot에 프로토콜/프롬프트 버전·원본·기획·개선 지시·이전 결과 연결을 비공개 보관한다. API 비용/사용량/지연은 그대로 기록한다. 원본+이전 참조의 총 12MB를 과금 claim 전에 검사한다.
- AI 평가 호출/점수/피드백 쓰기는 없다. 기존 평가·피드백은 보존/내보내기만 한다. 구버전 endpoint는 owner 확인 후 410, 구버전 evaluation step은 새 코드에서 no-op이다. 불확실한 과금 호출은 자동 재전송하지 않는다.

## 기능 검증 → 개선 → 재검증 루프

1. **오프라인 회귀:** `bun run check`, `bun run test:oauth`, `bun run test:local`, `bun run test:e2e`. 가짜 provider와 합성 이미지로 새 참조 순서·지시 전달·비용 원장·무평가·중복 호출 차단·권한·동의·이전 컷 비교를 확인한다.
2. **재현 가능한 지시:** `bun run test:photography`는 합성 baseline과 세 축의 단일 수정 4개를 버전/해시/근사 광학 조건과 함께 ignored `.tmp/photography-benchmark/manifest.json`으로 만든다. 출력 이미지가 없는 오프라인 벤치마크이므로 실사 품질 통과를 의미하지 않는다.
3. **운영 회귀:** 배포 후 공개 smoke와 합성 Mock 계정의 desktop/mobile 전체 흐름·다른 사용자 차단·정리를 수행한다. 키/이미지/지시를 CI 로그에 출력하지 않는다.
4. **사람이 직접 비용 동의:** 같은 원본·승인된 콘셉트·모델·품질을 유지하고 UI에서 새 baseline 1장 생성한다. 이전 `studio-v2`와의 비교는 지시 버전 외 조건도 다를 수 있으므로 인과 효과로 단정하지 않는다.
5. **한 항목씩 개선:** 필요한 경우 baseline의 ‘이 컷 개선’에서 세 축 중 하나를 선택하고 구체적 문제를 적는다. 이전 컷이 참조로 들어간 새 1장만 별도 동의한다. 예: ‘창 방향에 맞게 턱과 목의 그림자를 맞추고, 옷 전면은 읽히게 유지’. 세 축을 한꺼번에 바꾸거나 자동 N회 생성하지 않는다.
6. **관찰:** 같은 확대율로 원본/이전 컷과 비교한다. 빛·접촉 그림자·초점, 시선·피부·손·자세, 짜임·주름·주변 표면의 문제를 각각 글로 기록한다. 로고/색/핏이 바뀌면 다른 장점으로 상쇄하지 않는다. 점수·채택률 UI는 되살리지 않는다. 관찰 기록은 동의한 비공개 장소에 두고 저장소에는 합성 사례와 일반화한 결정만 남긴다.
7. **다음 변경:** 단일 상품에 맞춘 프롬프트 과적합을 피하고 로고/패턴/니트/유광 소재 등 권리 있는 추가 사례로 확인한다. 품질 문제면 해당 축의 프로토콜을 수정·버전 증가하고 1–3을 반복한다. 외부 유료 루프는 매번 사람의 동의가 필요하다.

## 현재 판정

구현·합성 계약 검증과 실제 출력의 개선 검증은 구분한다. 기존 실사용 5건은 생성 성공과 개선 필요성을 확인한 자료다. 새 프로토콜도 사용자 실행의 컷 개선 1건이 성공했고 새 generation attempt 1개·evaluation 0개 및 실제 비용 반환을 확인했다. 원본·실제 선택된 이전 참조·새 결과를 비공개 비교한 결과, 인물/구도 연속성과 노출·세부 표현 차이가 관찰됐다. 피부의 보정감과 작은 상품 표식의 차이는 남아 있으며 원본의 정보 한계도 존재한다. 이는 단일 사례의 정성 관찰로, 지시 변경만의 효과나 품질 개선을 입증하지 않는다. 사용자 최종 판단, 충분한 원본의 상품군별 단일 축 비교, 반복 생성의 동일인/로고 보존은 계속 검증해야 하며 ‘AI 티 제거 완료’라고 표시하지 않는다.

| 배경 | 강한 흐림과 장식적인 색감 | 야외도 길·건물·식물의 공간 관계가 읽힘; 흐림 자체는 존재 | 새 기본 gentle, 주변 맥락이 읽히는 분리, 명시적 강한 분리 선택은 유지 |
| 소재 | 매끈한 피부와 균일한 기모 인상, 작은 상품 표식 변형 | 거리에서 읽히는 주름/두께·봉제와 표면 반응의 차이 | 승인된 분석/불확실성 snapshot 전달, 모든 옷의 기모화·균일 미세텍스처·로고 굵기/채움 변형 억제 |
| 이전 컷의 영향 | v1 프롬프트가 layout 연속성도 요청함 | 게시 사진 비교만으로 인과 효과는 알 수 없음 | 이전 참조는 가상 인물 특징용, crop/피부 보정/노출/blur는 새로 구성 |

이것은 비교 표본의 차이이지 ‘모든 실제 쇼핑몰은 무표정·무보정·흰 배경’이라는 규칙이 아니다. 모델 내부 학습 데이터나 미공개 알고리즘이 원인이라고 확정하지 않는다. 현재 입력·지시가 미형 인물 화보 쪽으로 유도되고 직전 결과의 결함을 고정할 수 있다는 **엔지니어링 가설**을 먼저 교정한다. 얼굴을 작게 찍는 것만으로 인물 자연스러움이 해결됐다고 판단하지 않으며, 피부·시선·자세·재질의 일관성을 계속 확인한다.

v2는 생성 요청 시 상품 분석을 snapshot에 고정해 모델에 전달한다. 원본 이미지가 최우선이며, 분석의 소재 추정/confidence/불확실성은 그대로 불확실한 데이터다. 새 별도 AI 단계는 없다. 기본 프레이밍은 약 1.65m, 전신은 약 2.25m의 수직 시야를 가정하고, 명시적 close-up/접사는 약 0.8m의 근사 프로필을 사용한다. 3:4로 crop한 full-frame active sensor 높이 32mm와 초점거리로 카메라 거리를 연결한다. 이 수치와 머리 비중 지시는 측정된 결과나 신체 비율 변경 기능이 아니다.

기존 `balanced/separated`가 명시된 기획은 유지하며 새 기본값만 gentle이다. 이미 승인된 표정/장소/조명/명시적 접사는 존중한다. 일반 3/4 portrait를 beauty close-up으로 오해하지 않도록 했다. 컷 개선 UI에도 이전 컷에서 피부/노출/흐림까지 복제하지 않고 상품 가시성을 위해 구도가 바뀔 수 있음을 고지한다.

**v2 판정:** 합성 계약/프레이밍/참조 역할 및 배포 회귀 검증과, 새 인간 승인 출력의 품질 검증을 구분한다. v1의 사용자 개선 의견·실행 성공은 v2 성과로 표기하지 않는다. 충분한 원본으로 상품 전체의 가시성과 확대 시의 얼굴/로고를 함께 비교해야 한다.
