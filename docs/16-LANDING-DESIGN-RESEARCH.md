# 랜딩 디자인 리서치와 적용 — 2026-11-12

사용자는 기존 커스텀 SVG 일러스트와 톤을 바꾸고, 현대 SaaS 레퍼런스를 폭넓게 조사해 현재 개발된 기능으로 풍부한 랜딩을 구성하도록 요청했다. 아래는 공식 홈페이지의 내용과 실제 Chromium 화면을 확인한 관찰이다. 사이트는 계속 바뀔 수 있으며 수치/배치는 관찰 시점 기준이다. 타사 코드·사진·고객 로고·카피는 복제하지 않았다. 참조 캡처는 ignored `.tmp/landing-reference-*.png`, `.tmp/landing-reference-agent/`에만 있다.

## 선택한 방향

Granola의 편집적인 여백 + Linear의 제품 중심 구성 + Frame.io의 사진 크기를 조합했다. 단순히 색을 바꾸는 대신 페이지 구조를 다시 만들었다.

- 랜딩 한정 아이보리 `#f5f3ed`, 잉크 `#20221e`, 올리브/옅은 라임. 스튜디오는 기존 다크·네온 그대로다.
- Pretendard/Paperlogy 자체 호스팅을 유지하되 제목은 굵기를 줄이고 큰 문장/여백으로 구분한다.
- 기울어진 장식 카드/인물·의류 SVG/추상 원을 제거한다. 기존 브랜드 마크·표준 인터페이스 아이콘만 유지한다.
- 히어로는 상품 사진에서 다음 촬영까지의 가치 제안과 대형 기능 데모. 기능 설명은 준비→설계→비교·개선→재사용/기록→계정/FAQ→시작 순서다.
- 데모는 현재 앱의 사진 역할/촬영 선택/개선 지시/장면 전환/확대를 표현하는 별도 UI다. 실제 private 작업대가 공개되거나 고객 API를 호출하는 화면이 아니다. 선택/입력/확대만 실제 동작하며 생성·저장을 했다고 표시하지 않는다.

## 현재 구현과 맞춘 콘텐츠

의류 최대 3장, 촬영 레퍼런스/성인 인물 참조, 수정 가능한 상품 이해/촬영 콘셉트, 전신·바스트·디테일과 다양한 카메라 시점, 빛/소재 지시, 생성 시 편집 저장, 원본/이전 컷 비교·확대, 항목을 지정하는 개선, 브랜드 프리셋, 비용/지연/모델 이력, PNG 다운로드/데이터 내보내기, private 사진과 삭제를 설명한다.

완벽한 얼굴/상품 보존, 실제 촬영 대체 확정, 무료 AI 생성, 검증되지 않은 시간/비용 절감, 배치/팀/학습/자동 평가·합격 점수는 넣지 않았다. 비용과 보관에 관한 설명은 별도 계정 섹션/FAQ에 둔다.

## 독립 데모 사진의 출처

내장 image_gen 도구로 한 번 생성한 공개 마케팅 예시 사진이다. 실제 Photo Studio/OpenRouter의 유료 실행 결과나 고객 사진이 아니다. 허구 성인 모델·올리브 재킷을 동일한 톤으로 별도 제작했고, 페이지에서 예시임을 명시한다. 원본 생성물은 `.tmp/landing-assets/demo-contact-sheet.png`, 정확한 생성 프롬프트는 `.tmp/landing-assets/prompt.txt`에 로컬 보존한다. 프롬프트 요약은 ‘정확히 3등분한 가로 contact sheet: 올리브 코튼 재킷 단품, 같은 재킷을 입은 허구 성인 여성의 앉은 컷, 같은 인물·의상의 가까운 서 있는 컷; 따뜻한 회색 스튜디오/자연스러운 측면광; 글자·로고·UI·사용자 사진 없음’이다.

배포 파일은 아래 세 개이며 원본 512×1024 크기를 유지했다. Sharp로 equal-panel crop/WebP 압축만 수행했다. 총 약 110KB이고 외부 이미지 호스팅/폰트 요청/타사 고객 이미지를 추가하지 않았다.

- `apps/web/public/landing/demo-garment.webp` — 30,890 bytes
- `apps/web/public/landing/demo-shoot.webp` — 43,138 bytes
- `apps/web/public/landing/demo-detail.webp` — 38,990 bytes

고객 사진/키/식별자/프롬프트의 git 보관 금지는 유지한다. 별도로 제작해 공개용으로 정한 위 세 마케팅 사진만 예외적으로 정적 자산에 포함한다.
