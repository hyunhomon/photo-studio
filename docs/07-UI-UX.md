# UI/UX Specification — 상품 중심 스튜디오

## 기준

ADR-022는 한 화면의 목적과 다음 행동을 명확하게 하고 불필요한 정책/단계를 줄인다. Toss 공식 [Product Principles](https://toss.im/tossfeed/article/tossproductprinciples)의 Simplicity/Clear Action/One Thing/No More Loading 관점과 [Toss Design System](https://toss.tech/article/toss-design-system)의 일관된 패턴/접근성 관점을 참고한다. 실제 구현은 Astro/React Islands/Tailwind v4/Headless UI의 커스텀 컴포넌트이며 Toss UI kit를 도입하지 않는다.

- 다크 전용 charcoal/black, 형광 초록 primary #00F59B, Pretendard 본문/Paperlogy headline을 유지한다.
- 비용과 외부 처리는 실행을 결정하는 위치에 표시한다. 구현하지 않은 자동 평가·정확한 견적·품질 보증을 보이지 않는다.
- semantic HTML, label, focus-visible, Headless UI Dialog/Listbox/Tab/Combobox의 키보드 동작을 유지한다.

## 화면

| Route | 한 화면의 목적 |
|---|---|
| / | 간결한 가치 제안·하나의 주 CTA ‘사진으로 촬영 시작하기’·짧은 3단계 흐름 |
| /studio | 상품 사진 직접 등록, 여러 장/선택적 참조 미리보기 |
| /studio/products/:id | 중앙 원본/결과 작업대와 오른쪽 기획 inspector |
| /studio/presets | 재사용할 텍스트 방향 저장 |
| /studio/usage | 본인 호출/실제 비용 부분합/미확인 기록 |
| /studio/settings | 연결·내보내기·삭제 |
| /beta 및 과거 프로젝트 링크 | 현재 studio로 복귀하는 호환 안내/redirect, 프로젝트 생성 UI 없음 |

## 탐색과 등록

좌측 사이드바는 최근 상품과 검색을 제공한다. 프로젝트 목록/생성은 없다. 작은 화면은 메뉴 Dialog로 같은 상품 탐색을 연다. 접힘 여부 외 private 사진/프롬프트/목록은 브라우저 저장소에 캐시하지 않는다.

/studio에 바로 등록 폼을 둔다. 의류 1–3장의 선택된 이미지 썸네일·삭제·순서를 보여주고 첫 사진이 기본 원본임을 알린다. 선택적 인물/촬영감 참조도 업로드 전에 확인한다. 파일 선택/저장으로 AI를 실행하지 않는다. 타입/용량/권리·인물 동의 오류는 해당 폼에서 해결하게 한다.

## 상품 작업대

- 중앙에 원본/AI 결과를 계속 보여준다. 원본 썸네일 선택, 결과 선택, 확대, 이전 컷 비교, 다운로드와 컷 개선을 같은 맥락에서 제공한다.
- 오른쪽에 기획, 상품 이해, 촬영 콘셉트를 둔다. 탭/패널 전환은 중앙 캔버스를 제거하거나 다른 페이지로 보내지 않는다. 작은 화면은 패널을 쌓거나 별도 탐색으로 열되 이미지 비교를 유지한다.
- 촬영감 사진을 기획에 사용하면 사진 미리보기/외부 처리 동의를 확인한다. 레퍼런스 관찰(referenceNotes)은 관찰 요약으로 표시하며 정확한 카메라 추론이나 적용 성공으로 표시하지 않는다.
- 콘셉트 승인만으로 생성하지 않는다. 생성 Dialog에서 사용할 참조 사진을 확인·선택하고 별도 비용 동의 후 1장 요청한다. 기획의 연결 참조를 이어갈 수 있으나 삭제된 자료를 숨겨서 전송하지 않는다.

## 대기와 복구

인증 pending은 skeleton이며 실제 401 전 연결 폼을 노출하지 않는다. 네트워크/503은 재확인 UI로 복구한다. 분석/기획/생성의 대기는 작은 상태 카드만으로 끝내지 않고 중앙 이미지 영역에 충분한 크기의 skeleton/진행 상태/단계 설명을 표시한다. 직전 결과는 맥락으로 보존하되 새 완료 결과처럼 보이게 하지 않는다. 정확한 진행률을 모르면 %나 카운트다운을 만들지 않는다.

API 전송 이후 결과 불명확은 비용 확인 필요 상태로 남기고 자동 재전송하지 않는다. 사용자가 필요할 때만 새 비용 동의로 개선을 실행한다. 임시 dispatch 연결 재확인은 동일 작업 ID만 확인한다. 사진 속 상품/인물/소재 문제는 사람의 원본/이전 비교로 판단하고 숫자 점수·채택/폐기 피드백은 되살리지 않는다.

## 시각 자료의 정직성

랜딩의 벡터/합성 일러스트와 Mock 결과는 실제 AI 실사 성공 사례로 표시하지 않는다. 실제 참조 기반 품질 검증 상태는 구현 계획과 구분한다. 화면 전환/로딩은 reduced-motion을 존중하고 문서 흐름·초점 복귀·ARIA status를 제공한다.

ADR-024: 상품 이해/콘셉트는 화면에서 편집하고 생성 실행 시 함께 저장한다. 별도 수정 저장/콘셉트 승인 버튼은 사용하지 않는다. 생성 확인은 현재 편집 설정과 이미지 1회 비용에 대한 동의를 받는다. 편집값은 탭 전환에 유지하지만 생성 전 페이지를 떠나면 저장되지 않는다.
